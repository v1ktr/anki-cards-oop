# Anki — тренажёр перевода слов

Консольная игра на Python: программа показывает слово, вы вводите перевод.
Словарь можно хранить в локальном файле (`txt`, `tsv`, `json`) или загружать по HTTP.

Нужен **Python 3.9 или новее**.

```bash
python --version
```

## Возможности

- Динамическое меню: пункты появляются только если в словаре есть слова
- Обычная игра и поиск перевода
- Тренировка до первой ошибки
- Тренировка на время
- Загрузчики файлов и URL выбираются автоматически

## Установка

Все команды выполняются **из корня проекта** — папки, где лежит этот `README.md`.

### 1. Создайте виртуальное окружение

**Windows (PowerShell):**

```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

Если PowerShell запрещает запуск скриптов, выполните один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

**macOS / Linux:**

```bash
python3 -m venv venv
source venv/bin/activate
```

Пока окружение активно, в начале строки терминала обычно видно `(venv)`.

### 2. Установите проект

Для игры достаточно основных зависимостей:

```bash
pip install -e .
```

Для разработки (тесты и линтеры) установите extras `dev`:

```bash
pip install -e ".[dev]"
```

Флаг `-e` ставит пакет в режиме разработки: изменения в коде сразу видны без повторной установки.

## Запуск

С включённым окружением `(venv)`:

```bash
anki
```

По умолчанию используется словарь `src/anki/words.txt`. Источник можно указать явно:

```bash
anki --source=src/anki/words.txt
anki --source=words.json
anki --source=https://code.s3.yandex.net/fullstack_developer/python_words.txt
```

Либо без команды `anki`:

```bash
python -m anki.main
```

## Как пользоваться

После запуска появится меню. Пункты со словами скрываются, пока словарь пуст.

1. **Начать игру** — случайное слово, вы вводите перевод
2. **Добавить слова** — по очереди слово и перевод
3. **Тренировка до первой ошибки** — игра идёт, пока перевод верен
4. **Тренировка на время** — ограничение по секундам
5. **Найти перевод** — поиск слова в словаре
6. **Показать все слова** — список пар `слово - перевод`
7. **Выход** — сохранить словарь и закрыть программу

Чтобы выйти из игры, добавления слов или тренировки, введите `стоп`.

Добавленные слова записываются в выбранный источник только после пункта «Выход».

## Пример работы со словарём в Python

```python
from anki.anki import Anki

anki = Anki(words={"HELLO": "ПРИВЕТ"})
print(anki.words)

anki.words = {"WORLD": "МИР"}
print(anki.words)
```

Одной командой:

```bash
python -c "from anki.anki import Anki; a = Anki(words={'HELLO': 'ПРИВЕТ'}); print(a.words)"
```

## Разработка

Инструменты проверки настраиваются в `pyproject.toml`.

```bash
pytest
mypy src/anki
ruff check src tests
ruff format --check src tests
black --check src tests
```

- **pytest** — тесты
- **mypy** — проверка типов
- **ruff** — линтер и быстрый форматтер
- **black** — форматирование кода
